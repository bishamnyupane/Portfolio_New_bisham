# Profile Image Directory

Place your profile photo here:
`src/assets/images/profile/profile.webp`
or in the public folder:
`public/assets/images/profile/profile.webp`

Recommended format: WebP or PNG, square ratio (e.g. 400x400px or 800x800px).
If absent, the site gracefully renders a minimal monogram avatar with warm terracotta styling.
