# Project Screenshots Directory

Place your project screenshots here:
- `qaventis.webp`
- `yakkitchen.webp`
- `shopflow.webp`
- `learnsphere.webp`

Or in the corresponding public directory:
- `public/assets/images/projects/qaventis.webp`
- `public/assets/images/projects/yakkitchen.webp`
- `public/assets/images/projects/shopflow.webp`
- `public/assets/images/projects/learnsphere.webp`

Recommended format: WebP or PNG, 16:10 or 16:9 aspect ratio (e.g. 1280x800px).
If any screenshot file is missing, the site gracefully displays an editorial UI card mockup with project metadata without broken image icons.
